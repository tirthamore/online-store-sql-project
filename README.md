# Online Store SQL Project

## Project Overview

This project uses MySQL to manage and analyze an online store database. It demonstrates how SQL can be used to organize customer information, product details, orders, and order items, as well as answer business questions about sales and customer behavior.

## Objectives

* Store and manage customer information.
* Maintain product details and categories.
* Track customer orders and their statuses.
* Analyze product sales and customer spending.
* Practice SQL queries used in data analysis.

## Database Tables

The project contains four tables:

1. **Customers** — stores customer IDs, names, email addresses, and cities.
2. **Products** — stores product IDs, names, categories, and prices.
3. **Orders** — stores order dates, customer IDs, order totals, and statuses.
4. **OrderDetails** — stores products purchased in each order, quantities, and unit prices.

## SQL Concepts Used

* Database and table creation
* Primary keys and foreign keys
* INSERT and SELECT statements
* Filtering with WHERE
* INNER JOIN and LEFT JOIN
* Aggregate functions such as SUM and COUNT
* GROUP BY and HAVING
* Sorting with ORDER BY
* Limiting results with LIMIT
* Revenue and customer spending analysis

## Business Questions Answered

* Which products belong to the Electronics category?
* What is the value of shipped and delivered orders?
* Which products sell the most by quantity?
* Which product has the highest price?
* Which customers have placed multiple orders?
* How much have customers spent in total?
* Which products have never been ordered?
* How much revenue has each product generated?

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## How to Run

1. Open MySQL Workbench and connect to your MySQL server.
2. Open the SQL project script.
3. Execute the database, table creation, and sample data statements in order.
4. Run the analysis queries to explore the results.

## Conclusion

This project demonstrates foundational SQL skills through a practical online store scenario. It provides experience with relational database design, table relationships, joins, aggregation, and basic business analysis.
